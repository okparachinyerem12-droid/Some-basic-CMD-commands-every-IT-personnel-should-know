# Some-basic-CMD-commands-every-IT-personnel-should-know
Here are some basic cmd commands IT personnel should know

1) whoami: 
        Shows the username you are currently logged in as. IT personnel use this to confirm if you are logged in as Admin or a normal user when permissions fail.
<img width="116" height="35" alt="image" src="https://github.com/user-attachments/assets/1e0927b8-0ac9-4886-88c1-c930652a8ec4" />

2) mkdir
         It means “make a new folder”. You use it when you want to create a folder.
         Example: mkdir Assignment - it will create a folder named Assignment.
<img width="278" height="198" alt="image" src="https://github.com/user-attachments/assets/e4ca4c00-b1a7-4fd6-a826-4d926807e740" />

3) rmdir
      It means remove folder. You use it when you want to delete a folder.
       Example: rmdir Assignment - it will delete that folder.
<img width="459" height="360" alt="Screenshot 2026-10-14 221101" src="https://github.com/user-attachments/assets/88fe79cd-2d9e-4563-8515-5e796834a7b7" />

4) copy
        It is used to copy a file from one place to another.
     <img width="277" height="41" alt="Screenshot 2026-10-14 224936" src="https://github.com/user-attachments/assets/fa2e45e1-b55a-470a-8cfd-913982daf5aa" />
  
5) move
        It is used to move a file to another folder.
<img width="294" height="36" alt="image" src="https://github.com/user-attachments/assets/2c8b67e9-c51d-4fc0-a5c7-7a7812b17886" />

6) ren
      It means rename. You use it to change the name of a file.
      Example: ren bag.txt newbag.txt - changes bag.txt to newbag.txt.
<img width="309" height="31" alt="image" src="https://github.com/user-attachments/assets/2abb9726-1e4d-485b-b74a-bea4e1483f92" />

7) del
       It means delete. You use it to delete a file.
       Example: del newbag.txt - deletes the file.
<img width="166" height="31" alt="image" src="https://github.com/user-attachments/assets/e6652791-6f88-41d9-9dbe-466f21d50d45" />

 8) hostname
         Shows the name of the computer. IT personnel use this to quickly get the PC name for inventory, or when adding it to a domain/network. 
<img width="139" height="32" alt="image" src="https://github.com/user-attachments/assets/28055d48-f76c-440f-8eba-d2b8624edc66" />

9) ping
        Tests if another device is reachable on the network. It is used to check if the internet is working or if a server/printer is online.Example:
<img width="339" height="168" alt="image" src="https://github.com/user-attachments/assets/a54b0ec7-43f3-429e-b9fa-678072628f26" />

10) nslookup
         Finds the IP address behind a domain name. It checks DNS, When a website is not opening, to know if it's a DNS problem, we use nslookup.  Example: 
<img width="238" height="136" alt="image" src="https://github.com/user-attachments/assets/41e334d4-cc7c-4f07-8d3c-12fbeb36ffb5" />

11) dir
         Lists all files and folders in the current folder. It is used to see what's inside a folder without opening File Explore. Example: 
<img width="354" height="348" alt="image" src="https://github.com/user-attachments/assets/9d4fcab0-1c8c-44e9-9fd8-17ebb5682bce" />

12) cd
        Change Directory - moves you into another folder. It is used to navigate to where a program or log file is. Example: 
<img width="189" height="86" alt="image" src="https://github.com/user-attachments/assets/1a82bc5e-1d75-4c52-a0c8-ed3a874825d7" />

13) help
        Shows the list of all available commands and how to use them. You can use it when you forget the syntax of a command.
<img width="525" height="501" alt="Screenshot 2026-10-14 204535" src="https://github.com/user-attachments/assets/1f674559-3a90-4aa0-8721-f50269ac0b8e" />

14) tasklist
         Lists all running programs/processes. It is used to find a program that is hanging and get its PID to kill it. Example: 
<img width="497" height="192" alt="image" src="https://github.com/user-attachments/assets/4fc535a0-c0b7-4a6b-8ae7-f25880d06e0b" />

15) systeminfo
         Shows full details of the computer - OS version, RAM, CPU, uptime, updates. It is used to check if a PC meets requirements for software, or to find when it was last rebooted.
<img width="303" height="70" alt="image" src="https://github.com/user-attachments/assets/1a5108bf-d6a5-4080-b73d-9eafc5caf2ff" />

16) ipconfig
         Shows your network configuration - IP address, subnet mask, gateway. It is the number 1 network troubleshooting tool used to check if the PC got IP, or to release/renew IP.
